#### [tripforge](https://github.com/Abbhimanneu/Data-works/tree/main/tripforge)

Rough trip notes in. A day-by-day itinerary, an interactive map and a costed PDF out.

```text
"vietnam, 10 days, me + 1, 1.5L each,
 old quarter street food is a MUST ..."
            ↓
10-day plan · 5 cities · ₹2,16,524 vs ₹3,00,000
```

1. **Extract**: local LLM → schema-checked brief, cached
2. **Geocode**: OpenStreetMap at 1 req/s, cached
3. **Plan**: days per city, must-sees guaranteed
4. **Cost & check**: every rupee has a basis; errors stop the run
5. **Render**: dark PDF, Leaflet map, DuckDB history

### How I build

| Safe to re-run | Typed at the edges | Checked before shipped | AI where it's verified |
| --- | --- | --- | --- |
| Deterministic keys, cached steps | Inputs and model output validated first | Errors stop the run; warnings ship with output | LLMs draft, code decides what's true |
